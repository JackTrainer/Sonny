# Sonny
SONNY OS is an ultra-lightweight, agnostically unified open-source microkernel for any robot (arms, AMRs, drones, humanoids). Built in Rust and Zenoh, it replaces ROS 2 by eliminating memory leaks and latency. It features an abstraction layer via JSON and a secure WASM sandbox to run skills with zero setup. The future of robotics starts here.
